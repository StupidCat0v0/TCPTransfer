# TCPTransfer 网络传输
Relying on TCP to transfer folders or files, although it is not secure. But it's quite interesting. The part of transferring folders took me a long time, and in the end, AI optimized my code

Fill in the information according to the output instructions

Just right-click on the file or folder and copy the local address, it will automatically process (even with double quotes)

The client will download the file to the local download folder

The program output or comments are in Chinese

依靠TCP来传输文件夹或文件，尽管它并不安全。但这很有趣。传输文件夹的部分花了我很长时间，最后，AI优化了我的代码

按照输出的说明填写信息

只需右键单击文件或文件夹并复制本地地址，它就会自动处理（即使有双引号）

客户端会下载文件到本地下载文件夹

程序输出或注释是中文
